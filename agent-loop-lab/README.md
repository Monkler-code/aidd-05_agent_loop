# Тренажёр цикла агента

Клиентское приложение на React + Vite: один и тот же агент и одна и та же задача,
меняется только обратная связь.

- **Разомкнут** — агент не видит результата своей работы.
- **Почти замкнут** — агент видит сборку, тесты и скриншот интерфейса.
- **Замкнут** — агент видит результат и сам запускает проверку до сдачи.

Можно менять правила (зелёный пайплайн, подтверждение перед опасным действием,
запрет удаления) и «скилл агента» — вероятность корректного первого захода.
История прогонов показывает время, число ходов, вмешательства человека и
дефекты при приёмке.

## Запуск

```bash
npm install
npm run dev
```

## Сборка для GitHub Pages

```bash
npm run build
rm -rf ../docs/loop/* && cp -R dist/* ../docs/loop/
```

`vite.config.ts` использует `base: './'`, поэтому сборка работает из любого
подпути. Опубликованная версия: <https://olonho.github.io/agentic-class/loop/>.
