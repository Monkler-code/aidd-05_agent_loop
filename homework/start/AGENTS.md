# AGENTS.md — правила для агента в этом репозитории

## Что это

Небольшая доска задач: React 19 + TypeScript + Vite, тесты — Vitest.

## Подготовка (Node.js 20+)

```bash
npm install
```

## Команды

- `npm test` — прогнать тесты (Vitest, один прогон);
- `npm run dev` — dev-сервер Vite; URL он печатает сам, обычно `http://localhost:5173`;
- `npm run build` — проверка типов (`tsc --noEmit`) и production-сборка в `dist/`;
- `npm run preview` — посмотреть собранную версию.

## Где что лежит

- `src/tasks.ts` — логика доски: создание, переименование, фильтры, счётчик;
- `src/App.tsx` — экран;
- `src/tasks.test.ts` — тесты;
- `ISSUE-7.md` — отчёт пользователя.

## Правила работы агента

- Меняй только `src/tasks.ts` и `src/App.tsx`, если в задаче не сказано иное.
- Не читай и не меняй `src/tasks.test.ts`: приёмочные тесты пишет человек.
- Не добавляй зависимости и не меняй конфигурацию (`package.json`, `tsconfig`, `vite.config`).
- После изменений запусти `npm test` и приведи точный вывод: сколько прошло, сколько
  упало и какие именно тесты.
- Не удаляй и не переписывай данные и файлы за пределами `src/`.
- Если требование неоднозначно — остановись и задай вопрос, не угадывай.
- Вмешательства человека фиксирует человек в `INTERVENTIONS.md`; агент этот файл не ведёт.

## Что доказывает зелёный прогон

Зелёный `npm test` означает только то, что проверены перечисленные в тестах случаи.
Перед сдачей прогони `npm run build` и убедись, что diff ограничен разрешёнными файлами.
