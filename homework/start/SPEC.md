Requirements: Как пользователь, я хочу, чтобы любые уже имеющиеся пустые задачи (задачи из обычных пробелов, табуляций и непреррывных пробелов) не отображались на доске задач и их количество никак не учитывалось, а при попытке получить новые такие задачи с помощью добавления новой задачи или изменения старой программа выдавала предупреждение о некорректном названии задачи и оставляла прежнее название задачи.

Accpetance tests: 
1. Если пользователь переименовывает задачу в строку из одних пробельных символов, то переименовывание отклоняется, остаётся прежнее название, пользователю высвечивается предупреждение о некорректном названии задачи; пробелы по краям обрезаются. Пробельные символы: пробел, табуляция, неразрывный пробел U+00A0.
2. Доска не показывает задачи с пустыми задачами (задачи из обычных пробелов, табуляций и непреррывных пробелов), включая задачи, сохранённые до исправления.
3. Счётчик "Открытых" не учитывает пустые задачи.

Non-goals: 
1. Не изменяй интерфейс имеющейся программы.
2. Не добавляй новых функций и возможностей управления задачами.
3. Не удаляй старые пустые записи из хранилища.
4. Не изменяй имеющиеся функции, которые никак не связаны с обработкой пустых задач
5. Не изменяй и не добавляй функции, если это не влияет на проверку Acceptance tests

Files in scope:
Разрешено менять и читать только файлы src/tasks.ts, src/App.tsx, INTERVENTIONS.md

Defenition of done:
1. Автоматические тесты, запускаемые с помощью команды npm test завершаются успешно
2. Команда npm run build выполняется без ошибок
3. Acceptance tests удовлетворены
4. Изменения ограничены файлами src/tasks.ts, src/App.tsx, INTERVENTIONS.md
5. Никакие файлы, кроме SPEC.md, src/tasks.ts, src/App.tsx, INTERVENTIONS.md не были прочитаны
