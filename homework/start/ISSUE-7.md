# Issue #7 — пустая задача после переименования

**Как сообщил пользователь**

> Переименовал задачу: стёр название, оставил пробелы, нажал OK. Задача осталась в
> списке, и в «Открытых» появилась пустая строка. Ожидал, что название поменять не
> даст и покажет ошибку.

**Воспроизведение**

1. Открыть доску, нажать «Переименовать» у любой задачи.
2. Стереть название до пробелов и подтвердить.

**Фактически:** задача остаётся в списке с пустым названием.

**Ожидалось:** переименование отклоняется, остаётся прежнее название; пользователь видит
сообщение «Название не может быть пустым».

**Границы, о которых просил пользователь на созвоне**

- Пробелы по краям названия при создании — уже обрезаются, при переименовании нет.
- Табуляция и неразрывный пробел (U+00A0) — тоже считаются пустотой.
